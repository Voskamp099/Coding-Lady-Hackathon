# DESIGN.md

## 产品意象

**Time Mirror** —— 一颗用光种下的种子。每一次投喂回忆，光点便多一粒，孩子的轮廓便清晰一分。这是关于留住童年转瞬即逝瞬间的数字陪伴，光随记忆生长。

### 核心视觉：种子萌芽

开机界面以一颗光种为核心——金色晨雾中种子缓慢、优雅地生长（参考延时摄影），具有呼吸感（茎叶轻柔摇摆），被魔法光粒子环绕。这不是机械的动画，而是像延时摄影记录种子破土而出的瞬间。种子下方有6阶段进度条，标注"播种→破土→萌芽→抽叶→生长→茁壮"。

### 背景系统

所有页面统一使用金色系+绿色暖色渐变背景（`morandi-dawn` 类），营造朦胧梦幻的光影质感：
- 主背景：`linear-gradient(180deg, #FEF8E7 0%, #FFF8DC 30%, #F0F4E8 60%, #E8F0E0 100%)`（浅金→奶油金→淡绿→浅草绿的层叠渐变）
- 点缀：飘动的宫崎骏风格云朵（`.ghibli-cloud` + `animate-cloud-drift`/`animate-float-slow`），半透明白色/暖色
- 玻璃效果卡片：`backdrop-blur-xl` + 白色半透明底（`.glass-warm`），柔和金绿色边框
- 粒子画布：浅色拖尾，光点呈柔和金棕色 (#D4A843)
- 文字：主文字 `#5B4A1E`（深金棕），辅助文字 `#8B7B4A`（柔和金棕），弱化文字 `#8B7B4A/40`

### 主视觉：种子成长贯穿全程

种子从光中萌芽，长成小苗——这一视觉元素贯穿所有页面：
- **开机页**：金色晨雾中种子生长动画，带有呼吸感摇摆和魔法光粒子环绕
- **投喂页**：顶部小种子 + 进度条，随回忆增加成长度
- **镜像页**：漂浮旋转的镜子碎片，碎片反射宫崎骏风格场景
- **成长页**：种子图标 + 成长进度条
- **对话页**：种子图标作为AI头像
- **ParticleAvatar 组件**：Canvas 绘制系统，growth 参数(0-1)控制种子→小苗的成长阶段，带呼吸摇摆动画 + 魔法光粒子

### 气质与意象

晨雾缭绕的森林或广阔草原中，金色阳光透过薄雾洒下，空气中有细小的光尘在缓慢漂浮。一颗种子在光中悄然萌芽，茎叶轻轻摇摆，仿佛在呼吸。周围环绕着魔法光粒子，如萤火虫般温柔地闪烁。整个画面不是冰冷的技术展示，而是像一幅用水彩晕染出来的梦境。

**参考宫崎骏动画画风**：画面追求柔和大气层叠感——远景雾霭中的山峦轮廓、晨光穿透云层的大气透视。颜色不是平涂，而是像水彩在湿润的纸上自然洇开，边缘柔和过渡。整体有一种"被时间温柔包裹"的安宁感。

### 配色方案（金色系+绿色）

整体以金色系为主色调，搭配柔和的草绿色作为辅色。主色调包括浅金、奶油金、暖金棕、深金棕，辅以淡草绿、嫩叶绿。光影有朦胧、梦幻的质感，像阳光透过薄雾洒下来的感觉。

### 字体排版

- **中文正文**：Noto Sans SC（Google Fonts，清晰温暖，适合儿童产品语境）
- **数字/英文**：Inter（几何感与温度并存）
- **标题**：Noto Sans SC 600-700 字重，字间距略放宽（letter-spacing: 0.02em）
- **正文行高**：1.7，给予呼吸感
- **排版节奏**：大量留白，信息密度低，让每个元素都有舒展的空间

### 动效与交互

- **运动性格**：缓慢、有机，像呼吸。种子茎叶带 sin 波摇摆，模拟微风中的植物
- **缓动曲线**：cubic-bezier(0.4, 0, 0.2, 1) 为主，配合 ease-in-out
- **魔法光粒子**：围绕种子缓慢漂浮，带闪烁效果，如萤火虫
- **镜子碎片**：自转 + 围绕中心公转，悬停时放大或变化
- **悬停反馈**：柔和光晕扩散（box-shadow 莫兰迪色 blur），不使用缩放跳跃
- **页面切换**：淡入淡出 + 轻微向上位移，时长 400-600ms
- **按钮**：press 时内阴影微凹，像按下柔软的靠垫

### 响应式策略

- **手机**（<768px）：底部 Tab 导航，单列布局，全宽卡片
- **平板**（768-1024px）：底部 Tab 或侧边折叠，双列网格
- **桌面**（>1024px）：左侧导航栏，多列网格，种子画布更大

### 镜像页面：漂浮旋转镜子碎片

多块漂浮、旋转的"镜子碎片"悬浮在空中，像被魔法打碎的玻璃。每块碎片反射出宫崎骏动画风格的场景（如不同的自然风景、小动物或治愈场景）。碎片边缘有柔和的光晕，整体营造出梦幻、破碎又唯美的感觉。碎片缓慢自转和围绕中心公转，鼠标悬停时有放大或变化等微交互。

### 投喂页面规范

- **仅文字输入**：移除图片/视频/语音输入方式，只有纯文本输入框
- **时间类型多选**：五种时间类型支持多选（checkbox 风格），选中标签带色环高亮
- **AI 自动分类**：点击"AI 帮我分类"按钮调用 LLM 分析文字内容，自动推断时间类型
- **进度条**：数字分身进度条，基于回忆数量计算，显示百分比和下一阶段提示
- **孩子年龄**：投喂页顶部显示孩子年龄（≤1月=日龄，1月-2岁=月龄，>2岁=年龄）
- **最近记录**：仅展示最近3条回忆，点击"查看全部"跳转镜像页

### 成长页面规范

- 替换"叁天"为孩子年龄显示
- 孪生等级按年龄计算
- 气质九维/智能八维维度来源可点击，弹出对应回忆详情

### 标志性元素

在页面背景或装饰中，融入宫崎骏动画的标志性视觉元素：
- 极具体积感的大团白云（`.ghibli-cloud` + 多层叠加）
- 漂浮的飞行物（光粒子、花瓣等）
- 繁茂的植物元素（种子、小苗、叶片）
- 魔法光点（围绕种子或碎片闪烁）

### 设计禁忌

- 禁止冷色系（科技蓝、冰蓝、荧光绿）—— 但莫兰迪淡蓝、柔和草绿、淡粉等低饱和度自然色系是允许的
- 禁止深色/黑色背景（所有背景必须使用浅色莫兰迪暖色渐变，营造朦胧梦幻的氛围）
- 禁止单调的单一色铺满整个画面，需要有层次的颜色过渡（米黄→暖白→浅灰粉→淡紫灰）
- 禁止锐利直角（圆角 minimum 12px），所有 UI 元素用圆润无棱角的柔和线条
- 禁止快速机械动画（所有动画 > 300ms）
- 禁止高对比度硬阴影（阴影使用柔和色调，如 rgba(196,163,90,0.1)）
- 禁止 emoji 过度使用（界面克制，仅在必要处点缀）
- 禁止冰冷的数据表格展示回忆（用卡片、光点、有机形状）
- 禁止过于生硬冰冷的扁平化设计（需有手绘或水彩的笔触质感）

### 五种时间分类（王潇《五种时间》理论）

投喂回忆时使用五种时间标签分类，每种时间有独立的视觉色彩：

| 分类 | 色值 | 意象 |
|------|------|------|
| 生存时间 | `#78716C`（暖灰） | 日常的基石，朴素而必要 |
| 赚钱时间 | `#B45309`（深琥珀） | 主动成长，价值创造 |
| 好看时间 | `#BE185D`（玫瑰红） | 内外兼修，生命力之美 |
| 好玩时间 | `#0369A1`（天空蓝） | 好奇探索，自由飞翔 |
| 心流时间 | `#7C2D12`（深焦糖） | 全情投入，忘我之境 |

### 用户角色与继承

- **家长视角**（默认）：投喂回忆、查看面板、与AI对话记录成长
- **孩子视角**（继承后）：以第一人称回看成长记录、与AI对话回忆童年
- 继承操作不可逆，转移后家长视角关闭
